# Industry Icons

This directory is for industry-specific icons/images.

If using SVG icons, place them here:
- `manufacturing.svg`
- `construction.svg`
- `hospitality.svg`
- `healthcare.svg`
- `fnb.svg`
- `cleaning.svg`
- `shipping.svg`

Note: The current implementation uses inline SVG icons in the components, so this directory is optional for additional visual assets.
