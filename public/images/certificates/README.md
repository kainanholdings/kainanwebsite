# Certificate Images

Place scanned certificate images in this directory:

- `cert-jtksm.jpg` - JTKSM License C Certificate
- `cert-ssm.jpg` - SSM Certificate of Incorporation
- `cert-rba.jpg` - RBA Awareness Training Certificate
- `cert-pvip.jpg` - PVIP Authorization Document

## Requirements

- High resolution scans (minimum 1200px width)
- Optimized file size (under 500KB per image recommended)
- File format: JPG or PNG
- Properly cropped with minimal whitespace
